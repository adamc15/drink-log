# drink-log

Jack's simple personal drink tracker. A single static HTML file, local-storage only, hosted on GitHub Pages at https://adamc15.github.io/drink-log/. Public repo, intentionally — see Adam's standing preference for why that's fine here but isn't the default for his own original projects.

## Scope boundary — read before making any change here

This app stays a simple, local-only tracker. **Do not add** accounts, a backend, or any recovery-platform feature — support circles, accountability agreements, sobriety streaks/milestones, geofencing, sponsor tools, crisis resources, or anything else from the "Countable" concept. That work belongs in a separate, private repo (`countable`), even when an older planning document's phrasing (e.g. "Phase 1: migrate the existing app...") makes it sound like it belongs here.

If a task seems to call for adding a Countable-style feature to this app, stop and confirm with Adam first — don't assume this is the right place for it just because a plan or a review recommended it in the abstract.
